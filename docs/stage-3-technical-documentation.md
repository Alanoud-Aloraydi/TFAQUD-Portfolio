# Stage 3: Technical Documentation

## 1. User Stories and Mockups

### User Types

- **Patient:** The person who manages or follows their own care and can interact with the care circle.
- **Care Manager:** The person responsible for organizing and monitoring the patient's care.
- **Care Assistant:** A trusted person who participates in the patient's care by completing assigned responsibilities.

### Must Have

| ID | User Story |
|---|---|
| US-01 | As a Patient, I want to manage my own care plan, so that I can follow my medications, appointments, and health measurements independently. |
| US-02 | As a Care Manager, I want to create a patient profile, so that I can organize the patient's care. |
| US-03 | As a Care Assistant, I want to join a care circle by invitation, so that I can help care for the patient. |
| US-04 | As a Patient, I want to receive medication reminders, so that I do not miss my doses. |
| US-05 | As a Patient, I want to record that I took my medication, so that my Care Manager can follow my medication adherence. |
| US-06 | As a Care Manager, I want to organize the patient's medication plan, so that I can monitor the patient's treatment. |
| US-07 | As a Care Manager, I want to organize the patient's appointments, so that I can follow important healthcare visits. |
| US-08 | As a Care Manager, I want to record the patient's health measurements, so that I can monitor the patient's condition. |
| US-09 | As a Care Manager, I want to monitor the patient's daily care plan, so that I can see what has been completed and what needs attention. |
| US-10 | As a Care Manager, I want to review the patient's care history, so that I can understand what happened over time. |
| US-11 | As a Care Manager, I want to view care statistics and reports, so that I can monitor changes in the patient's care. |
| US-12 | As a Care Manager, I want to manage the patient's care circle, so that trusted members can share care responsibilities. |
| US-13 | As a Care Manager, I want to assign a care responsibility to a Care Assistant, so that responsibility for the task is clear. |
| US-14 | As a Care Assistant, I want to complete an assigned care responsibility, so that I can contribute to the patient's ongoing care. |
| US-15 | As a Care Manager, I want to know when an important responsibility has not been completed, so that I can intervene at the appropriate time. |
| US-16 | As a Patient, I want to send an emergency alert, so that my care circle can respond quickly. |
| US-17 | As a Care Manager, I want to create a visit sheet for the patient, so that I can use organized information during a medical visit. |
| US-18 | As a Patient, I want to know who can access my care information, so that I can protect my privacy. |

### Should Have

| ID | User Story |
|---|---|
| US-19 | As a Care Manager, I want to add medication information by photographing its package, so that I can enter it more easily. |
| US-20 | As a Care Manager, I want to monitor the remaining medication quantity, so that I can obtain more medication before it runs out. |
| US-21 | As a Care Manager, I want to identify measurements outside the expected range, so that I can notice situations that require follow-up. |
| US-22 | As a Care Manager, I want to share the patient's visit sheet, so that I can send it to a doctor or family member. |

### Could Have

| ID | User Story |
|---|---|
| US-23 | As a Patient, I want to send a voice message to my care circle, so that I can ask for help when writing is difficult. |

### Mockups

The MVP mockups were created using Figma. They visualize the main screens required to support the defined user stories for the Patient, Care Manager, and Care Assistant roles.

The Figma file includes the main care-management screens, including medication management, appointments, health measurements, care history, care-circle coordination, emergency alerts, and visit information.
