Render a composition to MP4, WebM, MOV, GIF, HLS, or a PNG sequence (hyperframes render v0.9.86)

USAGE hyperframes render [OPTIONS] [DIR]

ARGUMENTS

  DIR    Project directory

OPTIONS

                    -c, --composition=<composition>    Render a specific composition file instead of index.html (e.g. compositions/intro.html). Sub-compositions using <template> wrappers must be referenced from index.html via data-composition-src. Pass `.` (or omit the flag) to render the project's index.html.                                                                                                                                                                                                                                                                                                                                                              
                              -o, --output=<output>    Output path (default: renders/<project>_<YYYY-MM-DD>_<HH-MM-SS>.<ext>)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        
                                    -f, --fps=<fps>    Frame rate. Accepts integer (24, 25, 30, 50, 60, 120, 240) or ffmpeg-style rational (30000/1001 for NTSC 29.97, 24000/1001 for 23.976, 60000/1001 for 59.94). Range 1-240. Defaults to the composition's root data-fps, else 30.                                                                                                                                                                                                                                                                                                                                                                                              
                            -q, --quality=<quality>    Quality: draft, looks, delivery, or standard/high. looks is the default (CRF 16). delivery is high. MOV uses ProRes 4444 with alpha unless --prores-profile picks a 422 profile. (Default: looks)                                                                                                                                                                                                                                                                                                                                                                                                                             
                                    --skill=<skill>    Authoring skill that initiated this render (e.g. hyperframes). Recorded on render telemetry for per-skill usage breakdowns; ignored unless it is a slug.                                                                                                                                                                                                                                                                                                                                                                                                                                                                      
                                  --format=<format>    Output format: mp4, webm, mov, gif, png-sequence, hls (MOV/WebM render with transparency; png-sequence writes RGBA frames to a directory for AE/Nuke/Fusion ingest; gif is best at 15fps for PRs/docs; hls writes a VOD playlist directory — H.264/AAC, SDR only, no GPU encoding) (Default: mp4)                                                                                                                                                                                                                                                                                                                             
                              --gif-loop=<gif_loop>    GIF loop count, 0 = infinite. Range: 0-65535. Only used with --format gif.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    
        --hls-segment-seconds=<hls_segment_seconds>    HLS target segment length in whole seconds (default: 4). Range: 1-60. Also fixes the encoder GOP at segment x fps frames so every segment starts on a keyframe. Only used with --format hls.                                                                                                                                                                                                                                                                                                                                                                                                                                  
          --video-frame-format=<video_frame_format>    Source video frame extraction format: auto, jpg, png. Use png for UI recordings, screen captures, and color-sensitive source videos; alpha-capable sources always extract as PNG. (Default: auto)                                                                                                                                                                                                                                                                                                                                                                                                                             
              --page-motion-blur=<page_motion_blur>    Set off to disable authored page motion blur. Omit to keep the composition's setting.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         
                            -w, --workers=<workers>    Parallel render workers (number or 'auto'). Default: auto. Each worker launches a separate Chrome process (~256 MB RAM).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      
                                           --docker    Use Docker for deterministic render (Default: false)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          
                                              --hdr    Force HDR output even if no HDR sources are detected (Default: false)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         
                                              --sdr    Force SDR output even if HDR sources are detected (Default: false)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            
                                        --crf=<crf>    Override MP4/WebM encoder CRF. Mutually exclusive with --video-bitrate; unsupported for MOV.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  
                                    --start=<start>    Render from this second of the film (MP4). The clip starts at 0 and carries the audio of the span.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            
                                        --end=<end>    Render up to this second of the film (default: the end). Needs MP4, a whole frame rate of 24, 25, 30 or 60, and SDR.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          
                    --video-bitrate=<video_bitrate>    Target MP4/WebM video bitrate such as 10M. Mutually exclusive with --crf; unsupported for MOV.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                
            --keyframe-interval=<keyframe_interval>    MP4 keyframe interval in seconds, such as 2 (a keyframe at least this often; default: encoder's choice).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      
                        --max-bitrate=<max_bitrate>    MP4 peak video bitrate cap, such as 8M, kept alongside the quality target (default: uncapped).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                
                        --buffer-size=<buffer_size>    Buffer for --max-bitrate, such as 16M (default: twice --max-bitrate).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         
                  --prores-profile=<prores_profile>    MOV ProRes profile: 4444, hq, 422, lt, proxy (default 4444, keeps alpha; the others drop it).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 
                      --vp9-cpu-used=<vp9_cpu_used>    libvpx-vp9 -cpu-used value for WebM encodes (-8 to 8). Higher is faster with a larger quality/size tradeoff. Env: PRODUCER_VP9_CPU_USED.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      
          --chroma-subsampling=<chroma_subsampling>    MP4 chroma: 420 (default) or 444. 444 keeps full-resolution colour for thin coloured text and UI (yuv444p, lossless PNG capture, slower). Software encoder and SDR MP4 only; many players cannot decode 4:4:4. (Default: 420)                                                                                                                                                                                                                                                                                                                                                                                                 
                                              --gpu    Use GPU encoding (Default: false)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             
                                      --browser-gpu    Force host GPU acceleration for Chrome/WebGL capture. Default: auto (probe on first launch; fall back to software if no GPU). Use --no-browser-gpu to force software (SwiftShader).                                                                                                                                                                                                                                                                                                                                                                                                                                           
                                            --quiet    Suppress verbose output (Default: false)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      
                                     --lint-verbose    Show full lint findings instead of the summary line (Default: false)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          
                                            --debug    Write full render diagnostics and keep intermediate artifacts under the producer .debug directory. (Default: false)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           
                                      --best-effort    Allow output with structured capture-readiness warnings (default). Use --no-best-effort to fail on missing or unready media. (Default: true)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  
                                   --no-best-effort                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  
                                             --wait    Wait while another render of this user account runs, then start (default): renders side by side starve each other. Use --no-wait to fail at once instead. Env: HYPERFRAMES_RENDER_LOCK=off lets renders run side by side; HYPERFRAMES_RENDER_LOCK_DIR set to one folder in every account shares the slot across user accounts. (Default: true)                                                                                                                                                                                                                                                                                
                                          --no-wait                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  
                                           --strict    Fail render on lint errors (Default: false)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   
                            --include-outside-files    Also run .js and .mjs scripts the project references from outside its folder. Without it they are left out with a warning; images, video, audio, fonts and CSS outside the folder are always included. (Default: false)                                                                                                                                                                                                                                                                                                                                                                                                       
                             --refuse-outside-files    Leave out every file the project references from outside its folder. A --docker render passes it into the container when the received-files rule refuses those files on the host. (Default: false)                                                                                                                                                                                                                                                                                                                                                                                                                            
                                       --strict-all    Fail render on lint errors AND warnings (Default: false)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      
  --max-concurrent-renders=<max_concurrent_renders>    Max concurrent renders when using the producer server (1-10). Default: 2.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     
                            --variables=<variables>    JSON object of variable values, merged over the composition's data-composition-variables defaults. Example: --variables '{"title":"Hello"}'. Also a JSON file path, or - for stdin. Read inside the composition via window.__hyperframes.getVariables().                                                                                                                                                                                                                                                                                                                                                                      
                  --variables-file=<variables_file>    Path to a JSON file with variable values (alternative to --variables). The file must contain a single JSON object.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            
                                 --strict-variables    Fail render if any --variables key is undeclared or has a wrong type vs the composition's data-composition-variables. Without this flag, mismatches are warnings. (Default: false)                                                                                                                                                                                                                                                                                                                                                                                                                                            
                                    --batch=<batch>    Path to a JSON array of variable rows (or {"rows":[...]}). Renders one output per row.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        
            --batch-concurrency=<batch_concurrency>    Maximum number of batch rows to render at once. Default: 1, because each render already parallelizes across workers.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          
                                  --batch-fail-fast    Stop launching new batch rows after the first row failure. (Default: false)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   
                                             --json    With --batch, emit exactly one final JSON result document. Without --batch, print no progress, and on failure print the JSON error envelope. (Default: false)                                                                                                                                                                                                                                                                                                                                                                                                                                                                 
                          --resolution=<resolution>    Output resolution preset: landscape (1920x1080), portrait (1080x1920), landscape-4k (3840x2160), portrait-4k (2160x3840), square (1080x1080), square-4k (2160x2160), landscape-1440p (2560x1440), portrait-1440p (1440x2560), square-1440p (1440x1440). Aliases: 1080p, 4k, uhd, 1440p, qhd, 1080p-square, square-1080p, 4k-square, 1440p-portrait, 1440p-square. The composition is unchanged — Chrome renders at higher DPR (deviceScaleFactor) so the captured screenshot lands at the requested dimensions. Aspect ratio must match the composition; upscaling requires an integer multiple. Not yet supported with --hdr.
                            --page-side-compositing    Run shader transitions on a page-side WebGL canvas inside Chrome instead of the Node-side layered blend. ~6× faster for SDR shader-transition renders. Used for mp4, hls and gif output without HDR content; for mp4 and hls it usually turns off under --experimental-fast-capture. webm and mov output take the layered path. --no-page-side-compositing forces the layered path for mp4 and hls; gif always uses the page-side canvas. (Default: true)                                                                                                                                                                     
                         --no-page-side-compositing                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  
                --browser-timeout=<browser_timeout>    Puppeteer page-navigation timeout in SECONDS for the entry HTML. Increase when heavy compositions (many videos / fonts / asset requests) cannot reach domcontentloaded within the 60s default (see issue #1199). Accepts 0.001-86400 (24h cap). Note: this controls page.goto only — very heavy compositions may also need PRODUCER_PUPPETEER_PROTOCOL_TIMEOUT_MS / PRODUCER_PLAYER_READY_TIMEOUT_MS bumped (the post-goto window.__hf readiness poll has its own 45s budget). Env fallback: PRODUCER_PAGE_NAVIGATION_TIMEOUT_MS (MILLISECONDS).                                                                              
              --protocol-timeout=<protocol_timeout>    CDP protocol timeout in ms. Increase on slow/low-memory machines where Chrome operations time out. Default: 300000 (5 min). Env: PRODUCER_PUPPETEER_PROTOCOL_TIMEOUT_MS.                                                                                                                                                                                                                                                                                                                                                                                                                                                      
      --player-ready-timeout=<player_ready_timeout>    Timeout in ms for the composition player to become ready. Increase for complex compositions on slow hardware. Default: 45000 (45 s). Env: PRODUCER_PLAYER_READY_TIMEOUT_MS.                                                                                                                                                                                                                                                                                                                                                                                                                                                   
                                           --resume    Segmented capture only (HF_SEGMENTED_CAPTURE=true): reuse segments a previous run of the same composition and settings already finished, recorded in the local HyperFrames cache. Each reused segment is re-validated before it is skipped. (Default: false)                                                                                                                                                                                                                                                                                                                                                                  
                                    --keep-segments    Segmented capture only: keep locally cached segments after a successful render instead of deleting it. (Default: false)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       
                                  --low-memory-mode    Force the low-memory safe render profile on (--low-memory-mode) or off (--no-low-memory-mode). Safe mode pins to 1 worker, uses screenshot capture, and skips auto-worker calibration to avoid memory thrash on constrained machines. Default: auto-detected from total RAM (<= 8 GB). Env: PRODUCER_LOW_MEMORY_MODE.                                                                                                                                                                                                                                                                                                         
                        --experimental-fast-capture    Capture frames via Chrome's drawElementImage API instead of Page.captureScreenshot — reads DOM paint records directly, ~2x faster. Default: on where it can engage (macOS + hardware-GPU browser); incompatible compositions and self-verification failures fall back to screenshot capture automatically. Pass =false to disable. Env: PRODUCER_EXPERIMENTAL_FAST_CAPTURE.                                                                                                                                                                                                                                                   
              --frames-cache-dir=<frames_cache_dir>    Directory for the content-addressed extracted-frame cache. Use to relocate the cache off the system drive when the OS temp directory lives on a small partition (e.g. Windows C: exhaustion during long renders). Pass "off" / "none" / "false" / "0" to disable caching entirely (frames extract into the render's workDir and are cleaned up when the render ends). Default: <tmpdir>/hyperframes-extract-cache-<uid>. Env: HYPERFRAMES_EXTRACT_CACHE_DIR.
